# Reports (zgłoszenia) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Residents file public (estate) and private (own apartment, parking space, storage unit, billing, etc.) reports; staff triage them with type-specific status flows.

**Architecture:** New Prisma models `ParkingSpace`, `StorageUnit`, `Report`. All rules live in `domain/reports` (catalog, transitions, access) in the same style as `domain/packages`; server actions in `actions/reports.ts` wrap the domain; UI under `app/reports` + `components/reports`. Category catalog is in code, not in the DB. Visibility is derived from the category at creation and stored.

**Tech Stack:** Next.js 15 (App Router, server actions), Prisma 6 + Postgres, Clerk, Vitest (runs against the real DB), zod, shadcn/ui, Tailwind 4, sonner, date-fns.

## Global Constraints

Copied from [the spec](../specs/2026-10-20-reports-design.md):

- Report `type` values: `DEFECT REQUEST NOTICE QUESTION IDEA COMPLAINT`; visibility: `PUBLIC PRIVATE`; status: `NEW IN_PROGRESS RESOLVED APPROVED REJECTED CLOSED`.
- The user never picks visibility; it is derived from the category and stored on the row.
- Status flows: DEFECT/COMPLAINT `NEW → IN_PROGRESS → RESOLVED`; REQUEST `NEW → APPROVED | REJECTED`; NOTICE/QUESTION/IDEA `NEW → CLOSED`.
- RESIDENT sees all PUBLIC reports of own community + own PRIVATE reports; RECEPTIONIST, MANAGER, ADMIN see all reports of own community.
- Status changes: RECEPTIONIST/MANAGER/ADMIN; APPROVED/REJECTED only MANAGER/ADMIN. RESIDENT cannot change status.
- Every query is scoped by `communityId`; a resident may attach only a parking space / storage unit assigned to their own apartment.
- Every report creation and status change writes an `AuditLog` entry.
- Parking/storage data in the MVP comes from the seed script; no CSV import or admin UI.
- Out of scope: photos, comments, notifications, "+1" votes, contractor assignment, anonymous complaints.
- Domain code follows `domain/packages`; UI strings are Polish; nav titles are English like the existing ones.

## Working notes

- The working tree has unrelated uncommitted changes (theme work, including `components/MainNavigation.tsx`). Execute this plan in a git worktree cut from `main` (superpowers:using-git-worktrees) so commits stay clean. Always `git add` explicit paths, never `-A`.
- Tests run against the real Postgres in `DATABASE_URL` and `cleanupDatabase()` wipes every table. Do not point `.env` at data you care about; re-run `npm run db:seed` afterwards if needed.
- Start Postgres first: `docker compose up -d postgres`.
- Pure modules (`catalog.ts`, `transitions.ts`, `labels.ts`) use `import type` from `@/lib/generated/prisma` and string literals only, so client components can import them.

```prisma
enum ReportType {

  REQUEST
  NOTICE

  IDEA

  PRIVATE

  NEW

  APPROVED
  REJECTED
  CLOSED

model ParkingSpace {
  id           String   @id @default(cuid())
  communityId  String
  buildingId   String?
  apartmentId  String?
  number       String
  level        String?
  hasEvCharger Boolean  @default(false)
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt

  community Community  @relation(fields: [communityId], references: [id])

  @@unique([communityId, number])
  @@index([apartmentId])

model StorageUnit {
  id          String   @id @default(cuid())
  communityId String
  buildingId  String
  apartmentId String?
  number      String
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  community Community  @relation(fields: [communityId], references: [id])
  building  Building   @relation(fields: [buildingId], references: [id])
  apartment Apartment? @relation(fields: [apartmentId], references: [id])
  reports   Report[]

  @@unique([buildingId, number])
  @@index([apartmentId])
}

model Report {
  id             String           @id @default(cuid())
  communityId    String
  buildingId     String?
  apartmentId    String?
  parkingSpaceId String?
  storageUnitId  String?
  authorId       String
  category       String
  type           ReportType
  visibility     ReportVisibility
  title          String
  description    String
  status         ReportStatus     @default(NEW)
  urgent         Boolean          @default(false)
  createdAt      DateTime         @default(now())
  updatedAt      DateTime         @updatedAt
  resolvedAt     DateTime?

  community    Community     @relation(fields: [communityId], references: [id])
  building     Building?     @relation(fields: [buildingId], references: [id])
  apartment    Apartment?    @relation(fields: [apartmentId], references: [id])
  parkingSpace ParkingSpace? @relation(fields: [parkingSpaceId], references: [id])
  storageUnit  StorageUnit?  @relation(fields: [storageUnitId], references: [id])
  author       User          @relation(fields: [authorId], references: [id])

  @@index([communityId, visibility, status])
  @@index([authorId])
}
```

```ts
import type { ReportStatus, ReportType } from "@/lib/generated/prisma";

type Flow = Partial<Record<ReportStatus, ReportStatus[]>>;

const WORK_FLOW: Flow = { NEW: ["IN_PROGRESS"], IN_PROGRESS: ["RESOLVED"] };
const CLOSE_FLOW: Flow = { NEW: ["CLOSED"] };

const FLOWS: Record<ReportType, Flow> = {
  DEFECT: WORK_FLOW,
  COMPLAINT: WORK_FLOW,
  REQUEST: { NEW: ["APPROVED", "REJECTED"] },
  NOTICE: CLOSE_FLOW,
  QUESTION: CLOSE_FLOW,
  IDEA: CLOSE_FLOW,
};

export function nextStatuses(type: ReportType, from: ReportStatus): ReportStatus[] {
  return FLOWS[type][from] ?? [];
}

export function canTransition(
  type: ReportType,
  from: ReportStatus,
  to: ReportStatus,
): boolean {
  return nextStatuses(type, from).includes(to);
}
```

```ts
import prisma from "@/lib/prisma";
import { requireMembership, type SessionUser } from "@/auth/session";
import { writeAuditLog } from "@/domain/audit/log";
import {
  InvalidTransitionError,
  NotFoundError,
  TenantMismatchError,
  UnauthorizedError,
  ValidationError,
} from "@/domain/errors";
import {
  ReportVisibility,
  Role,
  type Prisma,
  type ReportStatus,
  type ReportType,
} from "@/lib/generated/prisma";
import { getCategory } from "./catalog";
import { canTransition } from "./transitions";

const STAFF_ROLES: Role[] = [Role.RECEPTIONIST, Role.MANAGER, Role.ADMIN];
const APPROVER_ROLES: Role[] = [Role.MANAGER, Role.ADMIN];
const FINAL_STATUSES: ReportStatus[] = ["RESOLVED", "APPROVED", "REJECTED", "CLOSED"];

const reportInclude = {
  author: true,
  apartment: true,
  building: true,
  parkingSpace: true,
  storageUnit: true,
} satisfies Prisma.ReportInclude;

export type ReportListItem = Prisma.ReportGetPayload<{ include: typeof reportInclude }>;

function membershipIn(actor: SessionUser, communityId: string) {
  const membership = actor.memberships.find((m) => m.communityId === communityId);
  if (!membership) {
    throw new UnauthorizedError(
      `User ${actor.id} has no membership in community ${communityId}`,
    );
  }
  return membership;
}

export async function createReport(
  actor: SessionUser,
  input: {
    communityId: string;
    categoryKey: string;
    type: ReportType;
    title: string;
    description: string;
    urgent?: boolean;
    parkingSpaceId?: string;
    storageUnitId?: string;
  },
) {
  const membership = membershipIn(actor, input.communityId);

  const category = getCategory(input.categoryKey);
  if (!category) throw new ValidationError(`Unknown category ${input.categoryKey}`);
  if (!category.types.includes(input.type)) {
    throw new ValidationError(`Category ${category.key} does not allow type ${input.type}`);
  }

  const title = input.title.trim();
  const description = input.description.trim();
  if (!title || !description) {
    throw new ValidationError("Title and description are required");
  }

  if (category.subject !== "parking" && input.parkingSpaceId) {
    throw new ValidationError(`Category ${category.key} does not take a parking space`);
  }
  if (category.subject !== "storage" && input.storageUnitId) {
    throw new ValidationError(`Category ${category.key} does not take a storage unit`);
  }
  if (category.subject === "parking" && !input.parkingSpaceId) {
    throw new ValidationError("A parking space is required for this category");
  }
  if (category.subject === "storage" && !input.storageUnitId) {
    throw new ValidationError("A storage unit is required for this category");
  }

  const isPrivate = category.visibility === "PRIVATE";
  if (isPrivate && !membership.apartmentId) {
    throw new UnauthorizedError(`User ${actor.id} has no apartment to file a private report for`);
  }

  return prisma.$transaction(async (tx) => {
    if (input.parkingSpaceId) {
      const space = await tx.parkingSpace.findUnique({ where: { id: input.parkingSpaceId } });
      if (
        !space ||
        space.communityId !== input.communityId ||
        space.apartmentId !== membership.apartmentId
      ) {
        throw new TenantMismatchError(
          `Parking space ${input.parkingSpaceId} is not assigned to the reporter's apartment`,
        );
      }
    }
    if (input.storageUnitId) {
      const unit = await tx.storageUnit.findUnique({ where: { id: input.storageUnitId } });
      if (
        !unit ||
        unit.communityId !== input.communityId ||
        unit.apartmentId !== membership.apartmentId
      ) {
        throw new TenantMismatchError(
          `Storage unit ${input.storageUnitId} is not assigned to the reporter's apartment`,
        );
      }
    }

    const report = await tx.report.create({
      data: {
        communityId: input.communityId,
        buildingId: isPrivate ? membership.buildingId : null,
        apartmentId: isPrivate ? membership.apartmentId : null,
        parkingSpaceId: input.parkingSpaceId,
        storageUnitId: input.storageUnitId,
        authorId: actor.id,
        category: category.key,
        type: input.type,
        visibility: category.visibility,
        title,
        description,
        urgent: input.urgent ?? false,
      },
    });

    await writeAuditLog(tx, {
      communityId: input.communityId,
      userId: actor.id,
      action: "REPORT_CREATED",
      entity: "Report",
      entityId: report.id,
      metadata: { category: category.key, type: input.type, visibility: category.visibility },
    });

    return report;
  });
}

export async function listReports(
  actor: SessionUser,
  communityId: string,
  filters: {
    visibility?: ReportVisibility;
    status?: ReportStatus;
    category?: string;
    urgent?: boolean;
    mine?: boolean;
  } = {},
): Promise<ReportListItem[]> {
  const membership = membershipIn(actor, communityId);
  const and: Prisma.ReportWhereInput[] = [];

  if (!STAFF_ROLES.includes(membership.role)) {
    and.push({
      OR: [{ visibility: ReportVisibility.PUBLIC }, { authorId: actor.id }],
    });
  }
  if (filters.mine) and.push({ authorId: actor.id });
  if (filters.visibility) and.push({ visibility: filters.visibility });
  if (filters.status) and.push({ status: filters.status });
  if (filters.category) and.push({ category: filters.category });
  if (filters.urgent) and.push({ urgent: true });

  return prisma.report.findMany({
    where: { communityId, AND: and },
    include: reportInclude,
    orderBy: [{ urgent: "desc" }, { createdAt: "desc" }],
  });
}

export async function getReport(actor: SessionUser, reportId: string): Promise<ReportListItem> {
  const report = await prisma.report.findUnique({
    where: { id: reportId },
    include: reportInclude,
  });
  if (!report) throw new NotFoundError(`Report ${reportId} not found`);

  const membership = membershipIn(actor, report.communityId);
  const isStaff = STAFF_ROLES.includes(membership.role);
  if (!isStaff && report.visibility === "PRIVATE" && report.authorId !== actor.id) {
    throw new NotFoundError(`Report ${reportId} not found`);
  }
  return report;
}

export async function changeStatus(
  actor: SessionUser,
  reportId: string,
  status: ReportStatus,
) {
  const report = await prisma.report.findUnique({ where: { id: reportId } });
  if (!report) throw new NotFoundError(`Report ${reportId} not found`);

  const allowedRoles = status === "APPROVED" || status === "REJECTED" ? APPROVER_ROLES : STAFF_ROLES;
  requireMembership(actor, report.communityId, allowedRoles);

  if (!canTransition(report.type, report.status, status)) {
    throw new InvalidTransitionError(
      `${report.type} report cannot go from ${report.status} to ${status}`,
    );
  }

  return prisma.$transaction(async (tx) => {
    const updated = await tx.report.update({
      where: { id: reportId },
      data: {
        status,
        resolvedAt: FINAL_STATUSES.includes(status) ? new Date() : null,
      },
    });

    await writeAuditLog(tx, {
      communityId: report.communityId,
      userId: actor.id,
      action: "REPORT_STATUS_CHANGED",
      entity: "Report",
      entityId: reportId,
      metadata: { from: report.status, to: status },
    });

    return updated;
  });
}

export async function listOwnedSpaces(actor: SessionUser, communityId: string) {
  const membership = membershipIn(actor, communityId);
  if (!membership.apartmentId) return { parkingSpaces: [], storageUnits: [] };

  const [parkingSpaces, storageUnits] = await Promise.all([
    prisma.parkingSpace.findMany({
      where: { communityId, apartmentId: membership.apartmentId },
      orderBy: { number: "asc" },
    }),
    prisma.storageUnit.findMany({
      where: { communityId, apartmentId: membership.apartmentId },
      orderBy: { number: "asc" },
    }),
  ]);
  return { parkingSpaces, storageUnits };
}
```

```ts
"use server";

import { z } from "zod";
import { revalidatePath } from "next/cache";
import { getCurrentUser } from "@/auth/session";
import { changeStatus, createReport } from "@/domain/reports";
import {
  InvalidTransitionError,
  NotFoundError,
  TenantMismatchError,
  UnauthorizedError,
  ValidationError,
} from "@/domain/errors";
import { ReportStatus, ReportType } from "@/lib/generated/prisma";

type ActionState = { message: string; success: boolean; fieldErrors?: Record<string, string> };

const createReportSchema = z.object({
  communityId: z.string().min(1),
  categoryKey: z.string().min(1),
  type: z.nativeEnum(ReportType),
  title: z.string().trim().min(1).max(120),
  description: z.string().trim().min(1).max(2000),
  urgent: z.boolean(),
  parkingSpaceId: z.string().min(1).optional(),
  storageUnitId: z.string().min(1).optional(),
});

export async function createReportAction(
  _prevState: ActionState,
  formData: FormData,
): Promise<ActionState> {
  const actor = await getCurrentUser();
  if (!actor) return { message: "Not signed in", success: false };

  const validated = createReportSchema.safeParse({
    communityId: formData.get("communityId"),
    categoryKey: formData.get("categoryKey"),
    type: formData.get("type"),
    title: formData.get("title"),
    description: formData.get("description"),
    urgent: formData.get("urgent") === "on",
    parkingSpaceId: formData.get("parkingSpaceId") || undefined,
    storageUnitId: formData.get("storageUnitId") || undefined,
  });

  if (!validated.success) {
    const fieldErrors = Object.fromEntries(
      validated.error.issues.map((i) => [i.path.join("."), "To pole jest wymagane"]),
    );
    return { message: "Uzupełnij wymagane pola", success: false, fieldErrors };
  }

  try {
    await createReport(actor, validated.data);
    revalidatePath("/reports");
    return { message: "Zgłoszenie wysłane", success: true };
  } catch (error) {
    if (error instanceof ValidationError) {
      return { message: "Sprawdź dane zgłoszenia", success: false };
    }
    if (error instanceof UnauthorizedError) {
      return { message: "Nie możesz złożyć tego zgłoszenia", success: false };
    }
    if (error instanceof TenantMismatchError) {
      return { message: "To miejsce nie jest przypisane do Twojego mieszkania", success: false };
    }
    console.error(error);
    return { message: "Nie udało się wysłać zgłoszenia", success: false };
  }
}

export async function changeReportStatusAction(
  reportId: string,
  status: ReportStatus,
): Promise<ActionState> {
  const actor = await getCurrentUser();
  if (!actor) return { message: "Not signed in", success: false };

  const parsed = z.nativeEnum(ReportStatus).safeParse(status);
  if (!parsed.success) return { message: "Nieprawidłowy status", success: false };

  try {
    await changeStatus(actor, reportId, parsed.data);
    revalidatePath("/reports");
    return { message: "Status zmieniony", success: true };
  } catch (error) {
    if (error instanceof NotFoundError) {
      return { message: "Nie znaleziono zgłoszenia", success: false };
    }
    if (error instanceof UnauthorizedError) {
      return { message: "Nie masz uprawnień do tej zmiany", success: false };
    }
    if (error instanceof InvalidTransitionError) {
      return { message: "Ta zmiana statusu nie jest możliwa", success: false };
    }
    console.error(error);
    return { message: "Nie udało się zmienić statusu", success: false };
  }
}
```

- [ ] **Step 2: Implement** `app/reports/page.tsx` (pattern: `app/packages/page.tsx`)

```tsx
import { redirect } from "next/navigation";
import { getCurrentUser } from "@/auth/session";
import { listOwnedSpaces, listReports } from "@/domain/reports";
import { ReportsList } from "@/components/reports/ReportsList";
import {
  ReportStatus,
  ReportVisibility,
  Role,
} from "@/lib/generated/prisma";

type SearchParams = {
  view?: string;
  visibility?: string;
  status?: string;
  category?: string;
  urgent?: string;
};

export default async function ReportsPage({
  searchParams,
}: {
  searchParams: Promise<SearchParams>;
}) {
  const user = await getCurrentUser();
  if (!user) redirect("/sign-in");

  // ponytail: first membership's community, same as /packages; needs a
  // community switcher once a user can belong to more than one.
  const membership = user.memberships[0];
  if (!membership) {
    return (
      <div className="container mx-auto pb-8">
        <h1 className="text-3xl font-bold mb-6">Zgłoszenia</h1>
        <p className="text-muted-foreground">
          Nie masz jeszcze dostępu. Poproś administratora o zaproszenie.
        </p>
      </div>
    );
  }

  const STAFF_ROLES: Role[] = [Role.RECEPTIONIST, Role.MANAGER, Role.ADMIN];
  const isStaff = STAFF_ROLES.includes(membership.role);
  const canApprove = membership.role === Role.MANAGER || membership.role === Role.ADMIN;

  const sp = await searchParams;
  const asEnum = <T extends string>(values: Record<string, T>, v?: string) =>
    v && v in values ? (v as T) : undefined;

  const reports = await listReports(
    user,
    membership.communityId,
    isStaff
      ? {
          visibility: asEnum(ReportVisibility, sp.visibility),
          status: asEnum(ReportStatus, sp.status),
          category: sp.category,
          urgent: sp.urgent === "1",
        }
      : sp.view === "mine"
        ? { mine: true }
        : { visibility: ReportVisibility.PUBLIC },
  );

  const { parkingSpaces, storageUnits } = await listOwnedSpaces(user, membership.communityId);

  return (
    <div className="container mx-auto pb-8">
      <h1 className="text-3xl font-bold mb-6">Zgłoszenia</h1>
      <ReportsList
        reports={reports}
        communityId={membership.communityId}
        isStaff={isStaff}
        canApprove={canApprove}
        canFilePrivate={Boolean(membership.apartmentId)}
        parkingSpaces={parkingSpaces}
        storageUnits={storageUnits}
      />
    </div>
  );
}
```
