# My profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/profile` page and a dashboard card showing the user's community, building, apartment, parking spaces and storage units.

**Architecture:** One domain function `getProfile` (reuses `listOwnedSpaces`) feeds a server page and a dashboard card. All text via next-intl.

**Tech Stack:** Next.js 15.5, React 19, Prisma 6, next-intl 4, shadcn/ui, Vitest.

## Global Constraints

From [the spec](../specs/2026-10-21-profile-design.md):

- Only the user's own data; no household members. Read-only.
- `getProfile` throws `UnauthorizedError` without a membership in the community; building = `membership.building ?? apartment.building ?? null`.
- All user-visible text in `messages/pl.json` and `messages/en.json` (identical keys and placeholders; parity test must pass). Polish is the source of truth; English natural.
- Dates/numbers via next-intl formatters if any are shown. No new dependencies.
- `/profile` protected in `middleware.ts`; signed out → `/sign-in`; no membership → `WaitingScreen`.
- Execute in worktree `.claude/worktrees/profile` (branch `feat/profile`); `node_modules` is symlinked (do NOT run `npm install`), `.env` copied. Commit with explicit `git add` paths. Tests use the real local Postgres and wipe tables.

- [ ] **Step 2: Implement `domain/profile/index.ts`**

```ts
import prisma from "@/lib/prisma";
import type { SessionUser } from "@/auth/session";
import { UnauthorizedError } from "@/domain/errors";
import { listOwnedSpaces } from "@/domain/reports";

export async function getProfile(actor: SessionUser, communityId: string) {
  const own = actor.memberships.find((m) => m.communityId === communityId);
  if (!own) {
    throw new UnauthorizedError(
      `User ${actor.id} has no membership in community ${communityId}`,
    );
  }

  const [membership, owned] = await Promise.all([
    prisma.membership.findUniqueOrThrow({
      where: { id: own.id },
      include: {
        community: true,
        building: true,
        apartment: { include: { building: true } },
      },
    }),
    listOwnedSpaces(actor, communityId),
  ]);

  const building = membership.building ?? membership.apartment?.building ?? null;

  return {
    firstName: actor.firstName,
    lastName: actor.lastName,
    email: actor.email,
    role: membership.role,
    community: { name: membership.community.name, address: membership.community.address },
    building: building ? { name: building.name, address: building.address } : null,
    apartment: membership.apartment
      ? { number: membership.apartment.number, floor: membership.apartment.floor }
      : null,
    parkingSpaces: owned.parkingSpaces.map((s) => ({
      id: s.id,
      number: s.number,
      level: s.level,
      hasEvCharger: s.hasEvCharger,
    })),
    storageUnits: owned.storageUnits.map((u) => ({ id: u.id, number: u.number })),
  };
}

export type Profile = Awaited<ReturnType<typeof getProfile>>;
```
